# Kuunganisha Salevi na GitHub Pages

Mradi umeandaliwa kwa repository `jumaachale420-lgtm/Salevi-poultry-farm-` na tovuti `https://jumaachale420-lgtm.github.io/Salevi-poultry-farm-/`.

1. Fungua terminal katika folda ya mradi na endesha:

   ```bash
   bash scripts/connect-github.sh
   ```

2. Fuata maelekezo ya kuingia na kuidhinisha GitHub CLI kwenye kivinjari. Usitume nenosiri au token kwenye mazungumzo.
3. Script itatumia repository iliyopo, itaweka Pages kutumia GitHub Actions, na itapakia mradi. Kila push inayofuata kwenye `main` itachapishwa kiotomatiki. Angalia matokeo kwenye [Actions](https://github.com/jumaachale420-lgtm/Salevi-poultry-farm-/actions/workflows/deploy.yml).

Git inahitajika. Linux ikikosa GitHub CLI, script hupakua toleo rasmi kwa muda na kuthibitisha checksum yake. Kwenye mifumo mingine, sakinisha [GitHub CLI](https://cli.github.com/) kwanza.

Ukurasa wa mwanzo utasasishwa. Kiungo cha zamani cha `Index.html` kitaelekezwa kwenye ukurasa wa mwanzo uliosasishwa. Endesha script tena baada ya kubadilisha mradi ili kuupakia. Script haitumii force push, na inajaribu kurejesha mipangilio ya awali ya Pages ikiwa push itashindikana.

Hakikisha bei, takwimu, ushuhuda na ahadi za huduma katika ukurasa mpya ni sahihi kabla ya kuuchapisha. Repository ni ya umma, kwa hiyo usiweke siri ndani ya faili za mradi.

Kusasisha tovuti hakufuti taarifa zilizowahi kuchapishwa kwenye historia ya GitHub. Historia na marejeo mengine ya umma vinahitaji kushughulikiwa tofauti; kuona [maelekezo ya GitHub](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
